# What if — a code-rendered music video

Song: "What if" by komzpa (`audio/whatif.mp3`, lyrics in `lyrics/lyrics.txt`, the author's own text).
Concept, palette, type and chapters: `docs/TREATMENT.md`. Build scope: `docs/BUILD-BRIEF.md`.

The video is a web app (`app/`, TypeScript + three.js, bun + Vite). It renders any song time
deterministically at 1920×1080 (or 3840×2160 with `--scale 2`), and as a native vertical cut at
1080×1920 (`--aspect 9:16`, each scene frames its own shots for it, TREATMENT r5 item 7); the same
code drives the live preview (`?aspect=9:16`) and the offline export.

## Engine credit

The engine (`app/src/engine/*`, `app/scripts/render.ts`) and the analysis pipeline (`analysis/`)
are forked from [mexicat/pdoom-video](https://github.com/mexicat/pdoom-video) (MIT, commit in
`reference/pdoom-video-commit.txt`; see `LICENSE`). None of the pdoom scenes, lyrics or plate designs
are used: every scene here is written from scratch for this song. Engine API notes for scene
authors: `docs/ENGINE.pdoom.md` (written for pdoom; the P(doom) HUD, plates and the spark/mask motifs
it mentions were removed in this fork, see below).

## Layout

- `data/lyrics.json`, `data/audio.json`: word timings, beats and chapter sections (from `analysis/`).
  The dev server serves `data/` and `audio/` from the repo root; `app/src/data-fallback/` stands in
  for a missing data file.
- `data/city.json`: the one city (TREATMENT r7): a Soviet radial-ring plan in km from the centre —
  districts (old centre inside the boulevard ring, microdistricts out to the ring road and beyond),
  streets (prospekts, the boulevard ring, the ring road, curved microdistrict streets), the metro
  (`Линия 2 «Заводская линия»` — the ride — plus a radial and a ring line), the promzona «Заводская»
  (the restricted zone behind a concrete fence), home, the walking route and each chapter's stop on it.
  Until the data step writes `data/city.json`, `app/src/data-fallback/city.json` (generated by
  `app/scripts/gen-city-fallback.py`) is served in its place. `app/src/city.ts` is the only reader:
  lookups, `ДОМ · x км` per chapter, the map drawing (`drawCityMap`) and `garble()`.
- `app/src/mojibake.ts`: glyph soup by one real wrong-codec transform, Win95 CP1251 read as CP1252
  («Проспект Строителей» → «Ïðîñïåêò Ñòðîèòåëåé», TREATMENT r9 note 1), through the browser's own decoders. No UTF-8
  readings («ÐŸÐ ÐžÐ”») and no CP866 box glyphs. A partial level garbles whole words only (step-by-step degradation
  goes word by word). Every string drawn is registered with its source and codec so QA can re-derive it (TESTPLAN A13).
- `app/public/fonts/ru/`: Soviet-signage faces (metro grotesque, stencil, typewriter) with their licences
  in `LICENSES.md`; `engine/type.ts` exposes them as `F.metro`, `F.stencil`, `F.typewriter`.
- `app/public/fonts/ka/`: Noto Sans Georgian for a few background signs in Mkhedruli (TREATMENT r9 note 2: `words`
  «პური», «აფთიაქი» across the prospekt, the far garage plate «სახელოსნო» in `tease`), drawn by `kaPlate` in `_kit.ts`,
  which checks every character against the font before drawing (no tofu). Never a beat's main sign, never soup.
- `app/src/contents.ts`: the contents table (lyric line → chapter → the handbook's Russian heading).
- `app/src/timeline.ts`: one entry per chapter; boundaries come from `data/audio.json` sections. There is
  no book card (TREATMENT r6): the video opens in the carriage. A chapter without its own scene module
  plays `scenes/placeholder.ts`.
- `app/src/textlog.ts`: every text item and object (hands) a frame draws — kind, full
  visibility, box, mojibake source, layout faults, `clip` (cut by scene geometry) — for the QA script.
- `app/src/scenes/_ru.ts`: the chapter line (`drawHeading`: the Russian heading lit letter by letter as
  the line is sung), fence stencils, typewritten taped notices, the red «М» sign.
- `app/src/scenes/_hands.ts`: the child's hands (a tapered raincoat sleeve with cuff and folds, wrist,
  palm, four fingers and a thumb): the torch hand (`torchPose`, `drawTorchHand`: the beam leaves the lens
  along the torch axis) and the free hand grabbing or laid flat (`drawOpenHand`).
- `app/src/scenes/_motifs.ts`: shared motifs — callouts, the torch (cone, line lighting, flicker),
  sky/fog/rain/glows, `NeonSign` (incl. dot-matrix `led` boards), the `CityScene` base class.
- `app/src/scenes/lost.ts`: one first-person sequence: the carriage seen from the bench opposite the door
  with the line diagram above it (one straight line, evenly spaced stations, names alternating above
  and below, the train as a lamp on the line; it checks its own layout); the doors close in the child's
  face at Садовая; the tunnel, the names past the ring break into mojibake; Заводская, an unfamiliar
  deep station, where the child steps out and finds a paper «СХЕМА ГОРОДА» on the wall, black until the torch
  lights it: the beam finds «ВЫ ЗДЕСЬ», then traces Линия 2 back to Садовая; the microdistrict street in the rain (panel blocks, heating
  main, garages, the promzona fence); the vestibule's roller shutter (drum housing, U-channel rails,
  corrugated slats) comes down on "closed"; `ДОМ · 6,3 км` and in through the promzona gate. Callout
  labels are placed once per callout, clear of every sign and board over its whole life, with a short leader
  that ends on its object. Platform signs seen from inside the carriage are logged through the wall's openings
  (window panes, the door gap, the leaves' windows): a sign split by a post or a door seam counts as cut.
  Proof views for gate 1: `?proof=hand|sign|shutter-half|shutter-closed|vestibule|street`
  (`render.ts stills --param proof=hand`).

## QA

Gate 2 runs every check on both aspects over the whole chapter:

```sh
cd app
bun scripts/qa-reading-time.ts --from 0 --to 26.4 [--aspect 9:16]   # A1-A8, A12, A13, B1, C1, A6 per frame
bun scripts/qa-contrast.ts     --from 0 --to 26.4 [--aspect 9:16]   # A9 on the rendered pixels
bun scripts/qa-drone.ts        [--rev <commit>]                     # A6 in the scene code (runs on old drafts too)
bun scripts/qa-av.ts --video ../out/whatif-video-draft-lost-YYYY-MM-DD-rN[-tiktok].mp4   # A10, A11 on the file
bun scripts/identity.ts        [--rev <commit>]                     # the input sha behind A11
```

`qa-reading-time.ts` implements A1 (reading time ≥ max(1.5 s, 0.4 s + chars/14, 0.3 s/word); background
signs glimpsed in a pan are logged as `scenery:` and exempt from reading time only), A2 (book, cover, printed
steps, page counter: 0 s), A3 (≤ 2 overlays incl. the sung line), A4 (text boxes vs signs, boards, the sung
line and each other), A5 (names from city.json; `ДОМ · x км` only decreases), A6 (no drone drawn in any
frame), A7 (lower-40% single prop coverage ≤ 20% of frames), A8 (TikTok safe area, cap height ≥ 70 px), A12
(the line diagram's own layout faults), A13 (no Latin letters or box glyphs anywhere; every mojibake string
re-derives from a Russian source by CP1251→CP1252, whole or word by word), B1 (the largest hand ≤ 25% of the frame) and C1 (no
text cut by the frame edge or by scene geometry for more than 0.5 s). Text is "fully visible" only when it
can be read: not during the fade from black, and wall-map text only inside the torch spot.

`qa-contrast.ts` (A9) renders frames at 4 fps and reads them back from the GPU. The chapter line logs its
inks (sung, front letter, unsung) with their boxes, and each is measured against the median of the pixels
around it that are not ink. Every other readable text is split by Otsu's threshold inside its box: the
lettering's stroke cores against the background class. Pass is ≥ 4.5:1, or ≥ 3:1 at ≥ 48 px.

`qa-av.ts` (A10, A11) measures integrated loudness (−14 ± 1 LUFS) and stream alignment. It finds the first
frame of the file in which each lyric line's red front letter appears (±60 ms of its aligned word). It checks
that the `…-rN.json` next to the file holds the work tree's input sha, that this differs from the previous
draft's (recomputed from its commit), and that the file's sha256 matches. Every script exits 1 and lists
each offender; `qa-reading-time.ts --debug <text>` prints per-frame visibility and boxes.

## Running

```sh
cd app
bun install
bunx vite                                  # preview at the printed URL (?t=12.5 to seek)
bun scripts/render.ts stills --t 5,14 --out ../out/stills
bun scripts/render.ts sheet --cuts --out ../out/sheets/cuts.png   # 4 frames around every chapter cut
nice -n 19 ionice -c3 bun scripts/render.ts video --samples 4 --from 0 --to 26.4 --out ../out/draft-lost-rN.mp4
nice -n 19 ionice -c3 bun scripts/render.ts video --aspect 9:16 --samples 4 --from 0 --to 26.4 --out ../out/draft-lost-rN-tiktok.mp4
bun scripts/deliver.ts --r N --date YYYY-MM-DD --chapter lost --prev-rev <r(N-1) commit> --poster <t>
```

Full-song renders can outlast short command-wrapper defaults: one measured full-render run took 3,462.9 s (~57m43s). Before each full-render command, set the external wrapper timeout explicitly above that measured duration, with margin for the current run; do not inherit a 300 s default or assume timeout 0 is universally appropriate. If a run stops early, preserve its partial files and logs as evidence, but do not treat them as deliverables. Accept only after both aspect renders have completed and finalized, then run QA against those actual output files; partial or truncated output never qualifies.

`deliver.ts` turns the two full-quality renders into the viewing copies
`out/whatif-video-draft-lost-YYYY-MM-DD-rN.mp4` and `…-rN-tiktok.mp4`. It bakes the poster (the master's own
frame at `--poster`) in as frame 0, so duration and frame count are unchanged. It sets the audio to −14 LUFS
with a fixed gain and a −1 dBFS limiter, encodes two-pass h264 under 15 MB, and writes the `…-rN.json`
identity manifest.

`render.ts` starts its own Vite server without live reload (or uses `--url`). On Linux, headless
Chrome gets hardware WebGL2 only through ANGLE on EGL; the script selects NVIDIA's EGL vendor when
present (`/usr/share/glvnd/egl_vendor.d/10_nvidia.json`) and prints the WebGL renderer it got.
`--swgl` forces software WebGL (SwiftShader); `--angle <backend>` picks another ANGLE backend.

## Changes to the forked engine

- Palette replaced with the TREATMENT palette (GLSL gets `C_<NAME>` for every key).
- P(doom) HUD readout, `plates.json`, the `plates` render mode and `public/plates` removed; the HUD
  keeps only the (off by default) crop marks and optional captions.
- The app loads `audio/whatif.mp3`; the export API is `window.__video`; the env switch is `VIDEO_NO_HMR`.
